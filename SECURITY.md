# Security Policy

## Supported Version

Security fixes target the latest release and the `main` branch.

## Reporting a Vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/markoblogo/decision-map/security/advisories/new). Do not open a public issue for a suspected vulnerability or include sensitive decision data in a report.

Expect an initial response within seven days. The report will be assessed before disclosure or remediation details are published.
